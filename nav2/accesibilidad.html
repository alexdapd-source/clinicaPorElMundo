Declaración de accesibilidad

Este sitio web ha sido diseñado teniendo en cuenta los principios de accesibilidad web, con el objetivo de facilitar el acceso a todos los usuarios, incluyendo aquellos con diferentes tipos de discapacidad.

  • El idioma principal de la página está identificado mediante el atributo lang="es".
  • Se han utilizado etiquetas semánticas de HTML5 como <header>, <nav>, <main> y <footer> para estructurar el contenido.
  • Las imágenes incluyen texto alternativo mediante el atributo alt.
  • Los encabezados están organizados jerárquicamente para facilitar la navegación por lectores de pantalla.
  • Los formularios están etiquetados correctamente con <label> para cada campo.
  • Se han implementado mecanismos de navegación como rutas de migas de pan y un mapa del sitio.

ClinicaPorElMundo se compromete a seguir mejorando la accesibilidad de este sitio conforme a las pautas WCAG 2.1 nivel AA.
